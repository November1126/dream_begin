# 项目名称：AI 硬件/软件 智能咨询智能体

> 基于 Dify 与 KG-LLM 驱动的高性能、响应式专业咨询解决方案。

## 🚀 项目概览

本项目集成多维数据采集、知识图谱增强以及极致的前端交互，旨在为用户提供关于厂商动态与 OpenRouter 数据的实时、精准咨询服务。

---

## 🛠 技术架构

项目采用分层架构设计，确保了系统的高可用性与可扩展性：

### 1. 前端展示层 (Frontend)

- **框架**: 微信小程序原生框架
- **样式**: **Tailwind CSS** (通过集成工具实现)
- **核心特性**:
  - 提供极致的移动端交互体验。
  - 原生支持**暗黑美学 UI**，适配多种设备视觉偏好。

### 2. 数据采集层 (Data Engine)

- **技术**: Python 自动化爬虫 + API 聚合
- **功能**:
  - 定时自动采集各硬件/软件厂商官网最新动态。
  - 实时同步 **OpenRouter** 数据，确保模型性能与价格信息的时效性。

### 3. 后端逻辑层 (Backend)

- **核心**: **FastAPI** (高性能 Python Web 框架)
- **数据库/BaaS**: **Supabase**
- **特性**: 实现轻量化、响应式的后端服务，利用 Supabase 的实时特性处理数据存储与同步。

### 4. AI 智能层 (Intelligence)

- **平台**: **Dify**
- **算法**: **KG-LLM (Knowledge Graph + LLM)** 融合引擎
- **作用**: 驱动咨询 Agent，通过知识图谱增强检索（RAG），实现专业领域的深度知识检索与高保真生成。

## 🏗 层级核心技术速查表

| 层级      | 核心技术                  | 关键作用                             |
| :-------- | :------------------------ | :----------------------------------- |
| **前端**  | 微信小程序 + Tailwind CSS | 移动端交互体验与暗黑美学 UI          |
| **数据**  | Python 爬虫 + API 聚合    | 各厂商官网及 OpenRouter 数据定时采集 |
| **逻辑**  | FastAPI + Supabase        | 轻量化响应式后端与实时数据存储       |
| **AI 层** | Dify + KG-LLM 融合引擎    | 专业领域的知识检索与 Agent 生成      |

---

## 🛠 开发环境配置

1.  **前端**: 使用微信开发者工具，安装 `tailwindcss-miniprogram-preset`。
2.  **后端**:
    ```bash
    pip install fastapi uvicorn supabase
    ```
3.  **爬虫**: 确保定时任务（Cron Job）正常运行。
4.  **AI 配置**: 在 Dify 控制台导入 DSL 文件，并配置知识库连接至 Supabase 向量库。
